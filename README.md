# Steam Points Calculator
Simple tool to convert Steam Points value into USD, EUR, RUB, or vice versa.

## Functions

### Convert Steam Points
Enter the value into the Points input, and you will see the converted value in the Currency input.

### Choose currency
Use the dropdown menu in the Currency input to select the currency. Now supported 3 currencies: USD, EUR, RUB, KZT.

### Flip conversions
Input the currency value into the Currency input to see how much Steam Points value it is. You can press the arrow to focus on the input (thearrow direction shows where the result will be).

### Clear results
Click outside of the empty space to clear all inputs.

## Conversion rates
The rates are taken from the Steam Points page and added to the code. Steam shows the current rate based on the user’s current location. The rates are not updating automatically here, and there are no global changes in rates for a few dates. If the rates change on the Steam page, I will update the rates too.

| Steam Points  | Currency | 
| ------------- | ------------- |
| 100  | 1$ (USD)  |
| 104  | 1€ (EUR)  |
| 98  | 100₽ (RUB)  |
| 95  | 500₸ (KZT)  |

## Self-hosted
The project is a simple HTML page without dependencies. You can download the repo and just open index.html in your browser.
